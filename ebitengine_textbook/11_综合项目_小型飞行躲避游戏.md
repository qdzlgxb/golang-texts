
## 11.1 项目目标

做一个小型飞行躲避游戏：

- 玩家控制飞行器上下左右移动。
- 障碍物从右向左移动。
- 玩家碰到障碍物游戏结束。
- 随时间增加分数。
- 有标题画面、游戏画面、结束画面。
- 有音效、调试信息、Web 构建。

## 11.3 数据结构

```go
type Vec2 struct {
    X, Y float64
}

type Player struct {
    Pos Vec2
    W, H float64
}

type Obstacle struct {
    Pos Vec2
    W, H float64
    Speed float64
}

type PlayScene struct {
    player Player
    obstacles []Obstacle
    tick int
    score int
}
```

## 11.4 游戏状态推进

```go
func (s *PlayScene) Update(g *Game) error {
    s.tick++
    s.updatePlayer()
    s.updateObstacles()
    s.spawnObstacles()

    if s.hitPlayer() {
        g.ChangeScene(NewGameOverScene(s.score))
    }
    s.score = s.tick / 60
    return nil
}
```

关键思想：`PlayScene` 只负责游戏局内逻辑，标题和结束不混进来。

## 11.5 玩家移动

```go
func (s *PlayScene) updatePlayer() {
    const speed = 2.2
    if ebiten.IsKeyPressed(ebiten.KeyA) || ebiten.IsKeyPressed(ebiten.KeyArrowLeft) {
        s.player.Pos.X -= speed
    }
    if ebiten.IsKeyPressed(ebiten.KeyD) || ebiten.IsKeyPressed(ebiten.KeyArrowRight) {
        s.player.Pos.X += speed
    }
    if ebiten.IsKeyPressed(ebiten.KeyW) || ebiten.IsKeyPressed(ebiten.KeyArrowUp) {
        s.player.Pos.Y -= speed
    }
    if ebiten.IsKeyPressed(ebiten.KeyS) || ebiten.IsKeyPressed(ebiten.KeyArrowDown) {
        s.player.Pos.Y += speed
    }

    s.player.Pos.X = clamp(s.player.Pos.X, 0, screenW-s.player.W)
    s.player.Pos.Y = clamp(s.player.Pos.Y, 0, screenH-s.player.H)
}
```

## 11.6 障碍物生成

```go
func (s *PlayScene) spawnObstacles() {
    if s.tick%45 != 0 {
        return
    }
    h := 20 + rand.Float64()*50
    y := rand.Float64() * (screenH - h)
    s.obstacles = append(s.obstacles, Obstacle{
        Pos: Vec2{X: screenW + 10, Y: y},
        W: 16,
        H: h,
        Speed: 1.5 + float64(s.score)/60,
    })
}
```

## 11.7 碰撞检测

```go
func rectsOverlap(ax, ay, aw, ah, bx, by, bw, bh float64) bool {
    return ax < bx+bw && ax+aw > bx && ay < by+bh && ay+ah > by
}

func (s *PlayScene) hitPlayer() bool {
    for _, o := range s.obstacles {
        if rectsOverlap(s.player.Pos.X, s.player.Pos.Y, s.player.W, s.player.H, o.Pos.X, o.Pos.Y, o.W, o.H) {
            return true
        }
    }
    return false
}
```

## 11.8 绘制

早期先用 vector：

```go
func (s *PlayScene) Draw(screen *ebiten.Image) {
    screen.Fill(color.RGBA{20, 24, 32, 255})
    vector.FillRect(screen, float32(s.player.Pos.X), float32(s.player.Pos.Y), float32(s.player.W), float32(s.player.H), color.RGBA{80, 200, 255, 255}, true)
    for _, o := range s.obstacles {
        vector.FillRect(screen, float32(o.Pos.X), float32(o.Pos.Y), float32(o.W), float32(o.H), color.RGBA{255, 100, 100, 255}, true)
    }
    drawText(screen, fmt.Sprintf("Score: %d", s.score), 8, 8)
}
```

后续替换为图片、动画、粒子、shader。

## 11.10 验收标准

你的项目达到以下标准，说明已经从入门走到中级：

- 能播放音效。
