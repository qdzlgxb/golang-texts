## 1.1 最小可运行程序

创建 `main.go`：

```go
package main

import (
    "image/color"
    "log"

    "github.com/hajimehoshi/ebiten/v2"
    "github.com/hajimehoshi/ebiten/v2/vector"
)

const (
    screenW = 320
    screenH = 180
)

type Game struct{}

func (g *Game) Update() error {
    return nil
}

func (g *Game) Draw(screen *ebiten.Image) {
    screen.Fill(color.RGBA{R: 20, G: 24, B: 32, A: 255})
    vector.FillCircle(screen, screenW/2, screenH/2, 30, color.RGBA{R: 240, G: 210, B: 80, A: 255}, true)
}

func (g *Game) Layout(outsideWidth, outsideHeight int) (int, int) {
    return screenW, screenH
}

func main() {
    ebiten.SetWindowSize(screenW*3, screenH*3)
    ebiten.SetWindowTitle("Hello Ebitengine")

    if err := ebiten.RunGame(&Game{}); err != nil {
        log.Fatal(err)
    }
}
```

运行：

```powershell
go mod tidy
go run .
```

你会看到一个窗口，中间有一个圆。

## 1.2 `Game` 接口

Ebitengine 游戏对象需要实现三个方法：

```go
type Game interface {
    Update() error
    Draw(screen *Image)
    Layout(outsideWidth, outsideHeight int) (screenWidth, screenHeight int)
}
```

三者职责不同：

- `Update`：推进游戏状态。处理输入、移动角色、碰撞检测、AI、计时器等。
- `Draw`：根据当前状态绘制画面。不要在这里改变核心游戏逻辑。
- `Layout`：返回逻辑分辨率。窗口大小可以变化，但游戏内部坐标可以保持稳定。

默认情况下，`Update` 以固定 tick 推进，常见目标是 60 TPS。`Draw` 跟显示刷新有关，通常也是 60 FPS，但不要把游戏逻辑绑定到 FPS。

## 1.3 状态放在哪里

不要把游戏状态散落在全局变量里。正确做法是放入 `Game` 结构体：

```go
type Game struct {
    x  float64
    vx float64
}

func (g *Game) Update() error {
    g.x += g.vx
    if g.x < 0 || g.x > screenW {
        g.vx = -g.vx
    }
    return nil
}
```

这样做的好处：

- 状态集中，容易保存/读取。
- 后续可以把 `Game` 拆成 Scene、World、Entity。
- 单元测试更容易写。

## 1.4 改造第一程序：移动小球

```go
package main

import (
    "image/color"
    "log"

    "github.com/hajimehoshi/ebiten/v2"
    "github.com/hajimehoshi/ebiten/v2/vector"
)

const (
    screenW = 320
    screenH = 180
)

type Game struct {
    x, y float32
    vx   float32
}

func NewGame() *Game {
    return &Game{x: 30, y: screenH / 2, vx: 2}
}

func (g *Game) Update() error {
    g.x += g.vx
    if g.x < 20 || g.x > screenW-20 {
        g.vx = -g.vx
    }
    return nil
}

func (g *Game) Draw(screen *ebiten.Image) {
    screen.Fill(color.RGBA{20, 24, 32, 255})
    vector.FillCircle(screen, g.x, g.y, 16, color.RGBA{240, 210, 80, 255}, true)
}

func (g *Game) Layout(outsideWidth, outsideHeight int) (int, int) {
    return screenW, screenH
}

func main() {
    ebiten.SetWindowSize(screenW*3, screenH*3)
    ebiten.SetWindowTitle("Moving Ball")
    if err := ebiten.RunGame(NewGame()); err != nil {
        log.Fatal(err)
    }
}
```

## 1.5 官方 rotate 示例应学什么

`rotate` 示例重点不是“旋转一张图片”，而是告诉你 Ebitengine 的基础绘制流程：

1. 加载图片资源。
2. 转成 `*ebiten.Image`。
3. 在 `Update` 中推进计数器。
4. 在 `Draw` 中创建 `DrawImageOptions`。
5. 用 `GeoM` 对图片做平移、旋转、缩放。
6. 调用 `screen.DrawImage`。

把这套流程记住，后续精灵、子弹、粒子、UI、地图块都是同一种模式。
