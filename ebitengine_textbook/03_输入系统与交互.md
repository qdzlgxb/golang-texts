## 3.1 持续状态与瞬时事件

游戏输入有两类：

- **持续状态**：某个键现在是否按着，例如 `ebiten.IsKeyPressed(ebiten.KeyArrowLeft)`。
- **瞬时事件**：某个键是否刚刚按下，例如 `inpututil.IsKeyJustPressed(ebiten.KeySpace)`。

角色移动通常用持续状态，菜单确认、发射子弹、暂停切换通常用瞬时事件。

## 3.2 键盘移动

```go
func (g *Game) Update() error {
    const speed = 2

    if ebiten.IsKeyPressed(ebiten.KeyArrowLeft) || ebiten.IsKeyPressed(ebiten.KeyA) {
        g.player.X -= speed
    }
    if ebiten.IsKeyPressed(ebiten.KeyArrowRight) || ebiten.IsKeyPressed(ebiten.KeyD) {
        g.player.X += speed
    }
    if ebiten.IsKeyPressed(ebiten.KeyArrowUp) || ebiten.IsKeyPressed(ebiten.KeyW) {
        g.player.Y -= speed
    }
    if ebiten.IsKeyPressed(ebiten.KeyArrowDown) || ebiten.IsKeyPressed(ebiten.KeyS) {
        g.player.Y += speed
    }

    if inpututil.IsKeyJustPressed(ebiten.KeySpace) {
        g.spawnBullet()
    }
    return nil
}
```

## 3.3 文字输入不要用物理按键拼

如果你要输入玩家名称、聊天文本、存档名，不应该手动把 `KeyA` 映射成字符 `'a'`。不同键盘布局、输入法、修饰键都会让这件事复杂化。

使用：

```go
g.runes = ebiten.AppendInputChars(g.runes[:0])
```

它表示当前环境下转换后的可打印字符。物理控制键仍用 `IsKeyPressed` 或 `inpututil` 处理。

## 3.4 鼠标与触摸

鼠标位置：

```go
x, y := ebiten.CursorPosition()
```

鼠标点击：

```go
if inpututil.IsMouseButtonJustPressed(ebiten.MouseButtonLeft) {
    x, y := ebiten.CursorPosition()
    g.handleClick(x, y)
}
```

触摸 ID：

```go
for _, id := range inpututil.AppendJustPressedTouchIDs(nil) {
    x, y := ebiten.TouchPosition(id)
    g.handleTap(x, y)
}
```

如果你的目标包含 Web/移动端，建议把鼠标点击和触摸点击统一为一个“指针输入”抽象。

## 3.5 手柄输入

手柄输入的基本思路：

1. 枚举连接的手柄 ID。
2. 优先使用标准布局 API。
3. 读取按钮和轴。
4. 设置死区 deadzone。

伪代码：

```go
for _, id := range ebiten.AppendGamepadIDs(nil) {
    if ebiten.IsStandardGamepadButtonPressed(id, ebiten.StandardGamepadButtonRightBottom) {
        g.jump()
    }

    x := ebiten.StandardGamepadAxisValue(id, ebiten.StandardGamepadAxisLeftStickHorizontal)
    y := ebiten.StandardGamepadAxisValue(id, ebiten.StandardGamepadAxisLeftStickVertical)
    g.moveByAxis(x, y)
}
```

## 3.6 输入映射层

不要让业务代码到处写 `KeyW`、`KeySpace`。建议做一层动作映射：

```go
type Action int

const (
    ActionLeft Action = iota
    ActionRight
    ActionUp
    ActionDown
    ActionConfirm
    ActionCancel
)

type Input struct{}

func (in *Input) Pressed(a Action) bool {
    switch a {
    case ActionLeft:
        return ebiten.IsKeyPressed(ebiten.KeyA) || ebiten.IsKeyPressed(ebiten.KeyArrowLeft)
    case ActionRight:
        return ebiten.IsKeyPressed(ebiten.KeyD) || ebiten.IsKeyPressed(ebiten.KeyArrowRight)
    case ActionConfirm:
        return ebiten.IsKeyPressed(ebiten.KeyEnter) || ebiten.IsKeyPressed(ebiten.KeySpace)
    default:
        return false
    }
}

func (in *Input) JustPressed(a Action) bool {
    switch a {
    case ActionConfirm:
        return inpututil.IsKeyJustPressed(ebiten.KeyEnter) || inpututil.IsKeyJustPressed(ebiten.KeySpace)
    default:
        return false
    }
}
```

后续你可以把手柄、触摸、鼠标都接到同一组 Action 上。

## 3.7 官方 keyboard 示例应学什么

官方 `keyboard` 示例展示了：

- 如何获取当前按下的按键集合。
- 如何显示物理键名。
- 如何使用 `inpututil` 辅助输入处理。
- 如何用 `SubImage` 高亮键盘图片的一部分。

这说明输入不只是“读键”，还常常和 UI 反馈绑定。
