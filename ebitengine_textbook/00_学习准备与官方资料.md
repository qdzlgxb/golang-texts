# 00. 学习准备与官方资料

## 0.1 Ebitengine 是什么

Ebitengine 是 Go 语言的 2D 游戏引擎，历史名称是 Ebiten。它的核心设计可以压缩成一句话：**几乎所有可渲染对象都是 `*ebiten.Image`，绘制就是把一个 Image 画到另一个 Image 上。** 屏幕是 Image，图片资源是 Image，离屏缓冲也是 Image。

这会让引擎的心智模型非常统一：

- 要画角色：把角色图片画到屏幕上。
- 要做旋转：给 `DrawImageOptions.GeoM` 设置旋转矩阵。
- 要做透明度/变色：给 `DrawImageOptions.ColorScale` 或相关颜色矩阵设置参数。
- 要做特效：把画面先画到 offscreen，再用 shader 或 blend 画回屏幕。

## 0.2 版本选择

本教材使用 Ebitengine v2.9.x 的 API 风格。建议安装 Go 1.24 或更新版本。

初始化项目：

```powershell
mkdir hello-ebitengine
cd hello-ebitengine
go mod init example.com/hello-ebitengine
```

添加 Ebitengine：

```powershell
go get github.com/hajimehoshi/ebiten/v2@latest
go mod tidy
```

验证官方 rotate 示例：

```powershell
go run github.com/hajimehoshi/ebiten/v2/examples/rotate@latest
```

如果你在 Windows 原生环境开发，Ebitengine 不要求你额外安装 C 编译器。Linux/macOS 下则需要按官方安装文档准备图形、音频相关依赖。

## 0.3 代码编辑器建议

推荐 VS Code：

- Go 官方扩展：`golang.go`
- 格式化：保存时运行 `gofmt`/`goimports`
- 调试：先用 `go run .`，等工程稳定后再配置 launch.json

建议目录：

```text
mygame/
  go.mod
  main.go
  internal/
    game/
      game.go
      player.go
      scene.go
    assets/
      assets.go
  assets/
    images/
    audio/
```

入门阶段不要过度拆分。等你有了角色、敌人、关卡、资源、音频之后，再拆成包。

## 0.5 本教材使用的命令约定

运行本地项目：

```powershell
go run .
```

运行官方 example：

```powershell

```

```powershell

```

## 0.6 Ebitengine 的核心包

常用包：

```go
import (
    "github.com/hajimehoshi/ebiten/v2"
    "github.com/hajimehoshi/ebiten/v2/inpututil"
    "github.com/hajimehoshi/ebiten/v2/vector"
    "github.com/hajimehoshi/ebiten/v2/text/v2"
    "github.com/hajimehoshi/ebiten/v2/audio"
)
```

含义：

- `ebiten`：窗口、主循环、图片、输入、绘制、shader。
- `inpututil`：一次性按下/释放这类边沿事件。
- `vector`：圆形、矩形、路径等矢量绘制。
- `text/v2`：新版文本渲染。
- `audio`：音频上下文和播放器。
