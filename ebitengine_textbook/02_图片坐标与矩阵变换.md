# 02. 图片、坐标与矩阵变换

对应官方 examples：

```powershell
go run github.com/hajimehoshi/ebiten/v2/examples/rotate@latest
go run github.com/hajimehoshi/ebiten/v2/examples/sprites@latest
go run github.com/hajimehoshi/ebiten/v2/examples/subimage@latest
```

## 2.1 坐标系

Ebitengine 使用常见 2D 屏幕坐标：

- 原点 `(0, 0)` 在左上角。
- X 轴向右为正。
- Y 轴向下为正。
- `Layout` 返回的宽高决定你的逻辑坐标空间。

如果 `Layout` 返回 `320, 180`，那么 `Draw` 中的 `screen` 就是一个逻辑上 320×180 的画布。窗口被放大时，Ebitengine 会自动缩放。

## 2.2 `*ebiten.Image`

你要区分三类 Image：

1. **资源 Image**：从 PNG/JPEG 解码后创建，用作角色、背景、图块。
2. **屏幕 Image**：`Draw(screen *ebiten.Image)` 传进来的目标。
3. **离屏 Image**：用 `ebiten.NewImage(w, h)` 创建，用作缓存、中间渲染、后处理。

简单创建一个纯色图片：

```go
img := ebiten.NewImage(32, 32)
img.Fill(color.RGBA{R: 255, G: 80, B: 80, A: 255})
```

绘制：

```go
op := &ebiten.DrawImageOptions{}
op.GeoM.Translate(100, 60)
screen.DrawImage(img, op)
```

## 2.3 `GeoM` 的顺序很重要

旋转图片时，你常常想“围绕图片中心旋转”。但 `GeoM.Rotate` 默认围绕当前坐标原点旋转。标准写法是：

```go
w, h := img.Bounds().Dx(), img.Bounds().Dy()

op := &ebiten.DrawImageOptions{}
op.GeoM.Translate(-float64(w)/2, -float64(h)/2)
op.GeoM.Rotate(angle)
op.GeoM.Translate(x, y)
```

含义：

1. 先把图片中心移到原点。
2. 围绕原点旋转。
3. 再把图片中心移动到世界坐标 `(x, y)`。

这正是官方 `rotate` 和 `sprites` 示例最值得学习的点。

## 2.4 `SubImage` 与图集

图集 sprite atlas 是 2D 游戏常用技术。把许多小图放在一张大图里，需要时用矩形区域取出。

```go
r := image.Rect(0, 0, 16, 16)
tile := atlas.SubImage(r).(*ebiten.Image)
```

注意：

- `SubImage` 返回的子图共享底层像素。
- 子图可以作为绘制源。
- 对同一张图集的多个子图连续绘制，通常更容易被批处理优化。

## 2.5 教学版：旋转精灵

```go
package main

import (
    "image/color"
    "log"
    "math"

    "github.com/hajimehoshi/ebiten/v2"
)

const (
    screenW = 320
    screenH = 180
)

type Game struct {
    img   *ebiten.Image
    tick  int
}

func NewGame() *Game {
    img := ebiten.NewImage(32, 32)
    img.Fill(color.RGBA{255, 100, 80, 255})
    return &Game{img: img}
}

func (g *Game) Update() error {
    g.tick++
    return nil
}

func (g *Game) Draw(screen *ebiten.Image) {
    screen.Fill(color.RGBA{20, 24, 32, 255})

    w, h := g.img.Bounds().Dx(), g.img.Bounds().Dy()
    angle := float64(g.tick) * math.Pi / 180

    op := &ebiten.DrawImageOptions{}
    op.GeoM.Translate(-float64(w)/2, -float64(h)/2)
    op.GeoM.Rotate(angle)
    op.GeoM.Translate(screenW/2, screenH/2)
    screen.DrawImage(g.img, op)
}

func (g *Game) Layout(outsideWidth, outsideHeight int) (int, int) {
    return screenW, screenH
}

func main() {
    ebiten.SetWindowSize(screenW*3, screenH*3)
    ebiten.SetWindowTitle("Rotating Sprite")
    if err := ebiten.RunGame(NewGame()); err != nil {
        log.Fatal(err)
    }
}
```

## 2.6 常见错误

### 错误 1：每帧创建大量图片

不要在 `Draw` 中反复 `ebiten.NewImage` 加载资源。资源应该初始化一次，绘制时复用。

### 错误 2：矩阵顺序写反

下面这段会得到完全不同的结果：

```go
op.GeoM.Translate(x, y)
op.GeoM.Rotate(angle)
```

因为平移后的坐标也会被旋转。

### 错误 3：把窗口大小当游戏逻辑尺寸

游戏逻辑尺寸由 `Layout` 决定，不应直接依赖实际窗口像素。
